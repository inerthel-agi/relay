02

YouTube Data API setup

Relay uses an API key, not OAuth: no client ID, secret or redirect URI.

01 Create a Google Cloud project console.cloud.google.com
  1. Open the Google Cloud Console and sign in.
  2. Top bar → Select a project → New project (for example Relay Music).
  3. Create it, then select that project so every later step stays on it.
02 Enable YouTube Data API v3 APIs & Services → Library
  1. Open APIs & Services → Library.
  2. Search for YouTube Data API v3.
  3. Open it → Enable, then wait for confirmation.
03 Create and restrict the API key Credentials → API key
  1. APIs & Services → Credentials → Create credentials → API key.
  2. Copy the key, then Edit / Restrict key.
  3. API restrictions → Restrict key → YouTube Data API v3 only.
  4. Application restrictions: None for home use, or IP addresses if stable. Do not use HTTP referrers.

Treat the key like a password. Never paste it in Discord or show it on stream.

04 Use it in Relay Music channel + Discord search
  1. Paste the key above and save, then choose the music channel on the Discord page.
  2. In that Discord channel, type a search (for example jennie mantra).
  3. Pick a result, then preview (about 30 s) or the full track. Tracks longer than 3 minutes are filtered out.

Full write-up: docs/youtube-api-setup.md in the Relay repository.

          Setup guide

          From Discord to OBS.

          Follow these steps once, then keep Relay running quietly in the system tray.

          01—06
          Recommended setup order

          Discord application, permissions, channels, OBS sources, widgets, then a live test.

          01 Create the Discord bot Application, bot token and client ID
          1. Open the Discord Developer Portal and create a New Application.
          2. Open Bot, create or reset the token, then copy it once.
          3. Copy the Application ID from General Information; this is the client ID.
          4. Paste both values into Relay. They are encrypted by Windows.
          02 Enable permissions and intents Required to read normal messages
          1. In Bot → Privileged Gateway Intents, enable Message Content Intent.
          2. Use Relay's invitation URL to add the bot to your Discord server.
          3. Give the bot View Channel and Read Message History in both watched channels.

          “Disallowed gateway intents” means Message Content Intent is still disabled; the token does not need regeneration.

          03 Configure Discord channels Separate media and message notifications
          1. Create one text channel for images, GIFs, videos and audio.
          2. Create a second text channel for message notifications.
          3. Select media and notification channels on Overview. Configure the Music channel on the Music page.
          4. Messages in this channel appear as visual notifications.
          04 Install the OBS Browser Sources Media and message notifications
          1. In OBS, add a separate Browser Source for each URL shown on Overlay.
          2. Use the visual URL for media and keep its transparent background.
          3. Use the Audio URL for Discord file audio and enable OBS audio control.
          4. Use the notifications URL for the PS5-style message card.
          5. Keep the private URLs unchanged; Relay reconnects them after every restart.
          05 Place the Windows widgets Move, lock and show on any monitor
          1. Open Overlay and show the media or notification widget.
          2. Leave it unlocked, drag it to the desired monitor and position.
          3. Lock it so mouse clicks pass through to applications underneath.
          4. Visibility, lock state and position are restored on restart.
          06 Troubleshooting Fast checks when nothing appears
          • No media: verify the selected media channel and the bot's channel permissions.
          • No message notification: verify the separate notification channel and send a new message.
          • No notification sound: enable the notification sound in OBS or Windows, then send a new message.
          • Blank OBS source: refresh it once and confirm Relay is running on the displayed local port.
          • Never regenerate a Discord token for a gateway-intent error; enable the intent instead.
          Copies a support report with versions, output status and recent errors. It never includes your token, private links or channel IDs.
          07 Privacy and regional rights GDPR and equivalent laws worldwide

          Relay has no telemetry, analytics, advertising or developer-operated collection service. It does not create a remote Relay account or user profile.

          Discord messages necessarily pass through Discord before reaching the bot. OBS sources and Windows widgets communicate locally through 127.0.0.1. Credentials are protected by Windows and preferences remain in the local application configuration.

          Your applicable rights depend on your place of residence and local law, including the GDPR in the EU/EEA and equivalent privacy laws in other regions. Relay does not infer or collect your location.
